A lightweight WordPress maintenance mode plugin with scheduling, access control, branding, social links, and a clean modern admin interface.

## Features

* Enable or disable Maintenance Mode
* Custom maintenance title and message
* Custom logo and favicon support
* Website name support
* Contact information
* Social media links
* Secret access URL for bypassing Maintenance Mode
* Automatic Maintenance Mode scheduling
* Light and Dark theme options
* Particle background option
* Responsive maintenance page
* Modern WordPress admin interface
* Unsaved changes indicator
* Sticky Save Changes bar
* Frontend "Powered by" branding
* Lightweight and easy to configure

## Requirements

* WordPress 6.0 or higher
* PHP 7.4 or higher

## Installation

1. Download or clone this repository.
2. Upload the `maintely-mode` folder to:
   `wp-content/plugins/`
3. Go to **WordPress Admin → Plugins**.
4. Activate **Maintely Mode**.
5. Open **Maintely Mode → Settings**.
6. Configure your maintenance page and save your settings.

## Configuration

After activation, open the Maintely Mode settings page to configure:

* Maintenance Mode
* Maintenance content
* Branding
* Contact information
* Social media
* Access control
* Design
* Automatic scheduling

## Access Control

Maintely Mode provides a Secret Access URL that allows authorized users to access the website while Maintenance Mode is enabled.

The Secret Access URL can be copied or regenerated from the Access Control settings.

## Scheduling

Automatic Scheduling allows Maintenance Mode to be enabled and disabled automatically using configurable start and end date/time settings.
